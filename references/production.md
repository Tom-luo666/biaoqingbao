# 切分、动态和验证

按当前会话与 SKILL.md 的工具权限处理，不因本文有示例流程而扩大授权。

## 独立 PNG

读取尺寸与 Alpha 极值。RGBA 模式不代表背景透明，必须有真实透明像素。先检查透明分隔带及每个角色和装饰的完整边界；仅在确为等分且不会裁掉内容时等分裁切。星光、眼泪和符号可能与主体分离，不能仅保留最大连通块。

统一透明画布，留安全边距，保持视觉大小与脚底基线稳定；含车等宽道具时优先完整，不强行等高放大。母版若跨格或重叠先修复，不能通过裁掉肢体掩盖问题。

## 本地循环 GIF

这是默认后处理阶段，以已经拆出的 PNG 为源。使用当前允许的本地工具，可编写并运行任务内复用脚本；遵守 SKILL.md 中的工具约束。默认约 1.2 秒、12 fps、512×512 画布，均可调整；这些是制作起点，不是平台限制。

按内容选择小幅弹跳、摇摆、抖动、缩放回弹或呼吸。不分层的 PNG 只能整体运动，真实眨眼、挥手和流泪需分层或新帧。

- 用 t=i/N 的周期函数采样，避免重复首帧作末帧造成停顿，保持位置与速度衔接。
- 按所有帧联合边界留余量，旋转和弹跳不能裁掉发丝或符号。
- GIF 只有索引透明，没有 PNG 的连续 Alpha，保留 PNG 原稿，不承诺无损透明边缘。
- 不透明颜色最多用 255 个调色板项，单独保留透明索引，避免把黑发、线稿映射为透明。
- 设置合适的 disposal 避免残影，设置无限循环，然后实际解码各帧检查。
- GIF 延时以百分之一秒计，报告编码后的真实时长与平均帧率，不将请求的 12 fps 当成实测值。

## 视频路线

选与人物、服饰和道具冲突最少的纯色幕。本参考有绿色圆点、蓝色眼泪和粉色桃心，不能默认任何色幕都安全。保留透明原稿。提示视频模型固定镜头，各格原位动作、无跨格、无串动作、背景纯色不变、首尾可循环；视频阶段不假定 Alpha 会保留。

根据全片运动范围和背景间隔决定固定裁切区域，不逐帧改变裁框引起抖动。没有稳定分隔时重新生成或单独修复问题格。

从边框连通的近背景色区域开始去底，容差考虑压缩噪声，不全局删除所有同色像素。此方法也有局限：同色服饰与背景相接仍可能误删，被肢体围住的背景孔洞可能残留。检查衣服、发丝、道具和孔洞，必要时结合掩膜或换色幕，处理溢色但不新增边框。保持时间顺序，缩短时长时说明剪裁范围。

## 验证与打包

PNG 检查真实透明、数量、边界及命名。GIF 解码检查透明索引、循环、帧数、延时、画布一致性和动作完整；浅色与深色底预览边缘、首尾衔接和残影。不能只凭扩展名或 loop 标记判定质量合格。

超大文件按需求调整尺寸、帧率、时长和调色板，记录变化。平台当前导入限制当次核实，不写死未验证的微信额度或尺寸。ZIP 仅收录成品、必要预览和清单，用户未要求时不包含原始人物照片或无关文件。
