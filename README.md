# biaoqingbao

一个用于 Codex 的照片表情包技能：真人大头搭配卡通小身体，先选择 Emoji 元素，再制作整套表情。

## 使用流程

1. 调用 `$biaoqingbao`，查看分类小表情并选择元素或组合，也可以让助手随机搭配。
2. 上传人物照片，生成相同人物的透明九宫格。
3. 继续以九宫格为源拆分独立 PNG，制作轻量循环 GIF。
4. 检查透明背景、边界和动画帧，交付 PNG、GIF、预览、报告与 ZIP。

例如：

> 使用 $biaoqingbao，先让我选择小表情，再按我上传的人物照片制作九宫格，并完成后续 PNG、GIF 和打包。

> 使用 $biaoqingbao，选择 😭＋🍕、😎＋🛵、🥳＋🎂 等九组，人物用我上传的照片。

用户明确只要静态或母版时，技能遵循该范围。

## 安装

将本仓库文件放入 `$CODEX_HOME/skills/biaoqingbao/`，使 `SKILL.md` 位于该目录根部。重新打开会话后使用 `$biaoqingbao`。

## 文件

- `SKILL.md`：选元素、生成与完整交付流程。
- `agents/openai.yaml`：技能显示信息与调用示例。
- `assets/style-reference.png`：混合媒介画风参考，不是新任务的人物身份参考。
- `references/production.md`：裁切、透明 GIF、视频处理与验证规则。
- `references/source.md`：灵感来源与素材说明。

## 能力边界

这是技能说明与风格资源，不是独立运行的软件。图片生成需要可用的图像工具，后续处理由助手使用当前环境允许的工具或任务脚本实际完成；仓库不包含通用批处理程序。默认 GIF 为原图的位移、旋转、缩放等轻量动画，不等同于自然眨眼、挥手或生成式视频。平台导入要求需按实际使用环境检查。

仅技能文件与内置风格参考属于此上传包，不包含用户本人的照片、本次生成的人物表情或工作区其他文件。
