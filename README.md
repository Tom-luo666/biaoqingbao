# biaoqing

根据人物照片制作真人大头与扁平手绘小身体结合的 Meme 表情包。

- 从分类表情库选择 9 组元素，或随机组合。
- 生成透明九宫格、9 张 PNG、约 1 秒轻微循环动画及 9 个独立 GIF。
- 保留完整人物和道具，配置与切分记录统一放入 config 文件夹。

将仓库内容放入名为 biaoqing 的技能目录，并调用 $biaoqing，提供人物照片。主入口见 [SKILL.md](SKILL.md)。

图片生成使用运行环境内置工具；本地切分脚本依赖 Python 和 Pillow。轻微动画采用贴纸整体平移、旋转等方式，不等同于生成新的肢体动作。

内置图片仅作画风参考，人物身份以新提供的照片为准。
